# MiniCraft

Um jogo de construção e exploração em um mundo de blocos, criado para ser simples, leve e divertido.

---

## Sobre o projeto

MiniCraft é um jogo voxel inspirado na ideia de explorar, construir e interagir com um mundo formado por blocos.

O projeto foi desenvolvido com foco em uma experiência simples, visual próprio e bom desempenho, especialmente em dispositivos móveis.

---

## Características

- Mundo gerado proceduralmente
- Sistema de chunks
- Construção e destruição de blocos
- Diferentes tipos de blocos
- Sistema de água com níveis e propagação
- Inventário
- Hotbar com 9 espaços
- Controles para dispositivos móveis
- Sistema de mundos
- Salvamento local
- Configurações personalizáveis
- Distância de renderização configurável
- Distância da neblina configurável
- Sombras
- Mipmapping
- Iluminação dinâmica
- Ciclo de dia e noite
- Otimizações para melhor desempenho

---

## Controles

### Celular

O MiniCraft possui controles adaptados para telas sensíveis ao toque.

- Joystick: movimentação
- Área de toque: câmera
- Botão de pular
- Botão de descer
- Botões para colocar e quebrar blocos
- Inventário
- Hotbar

---

## Desempenho

O projeto foi desenvolvido pensando em manter uma experiência leve mesmo em dispositivos com hardware mais limitado.

Entre as otimizações estão:

- Culling de faces
- Sistema de chunks
- Distância de renderização configurável
- Neblina configurável
- Mipmapping
- Iluminação otimizada
- Sombras leves
- Geração procedural

A ideia não é simplesmente adicionar o máximo de recursos possível, mas encontrar um equilíbrio entre visual, funcionalidade e desempenho.

---

## Visual

O MiniCraft possui uma identidade visual própria.

O objetivo é manter um visual simples, limpo e reconhecível, sem depender de uma grande quantidade de efeitos para tornar o jogo interessante.

---

## Tecnologia

O projeto utiliza:

- HTML
- CSS
- JavaScript
- Three.js

Grande parte do projeto está concentrada em um único arquivo HTML, tornando o projeto simples de executar e testar.

---

## Filosofia do projeto

A ideia do MiniCraft é simples:

> Fazer bem aquilo que o jogo precisa fazer.

Quantidade de código, quantidade de arquivos ou quantidade de recursos não são o objetivo principal.

O foco está em criar uma experiência funcional, agradável e leve.

---

## Status

O MiniCraft está em desenvolvimento.

Novos recursos, melhorias de desempenho, ajustes visuais e correções podem ser adicionados ao longo do desenvolvimento.
